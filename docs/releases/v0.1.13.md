# PDA 扫码登记工具 v0.1.13 · 首次公开测试版

用于现场设备扫码登记、固定资产清单盘点与蓝牙标签打印，可在 PDA 本机离线使用。

## 支持设备与实测情况

| 类型 | 明确支持的设备 / 规格 |
| --- | --- |
| PDA | **海康机器人 Hikrobot MV-IDP5204**，已有 Android 11 实机回归记录 |
| 打印机 | **德佟 DP30S 蓝牙标签打印机**，使用者已现场验证蓝牙连接和实际打印 |
| 标签纸 | **宽 30 mm × 高 20 mm**，当前模板与打印固定采用此规格 |

其他 Android 8.0 及以上 PDA 可尝试广播或键盘输入接入，需逐型号验证。当前不承诺其他打印机及纸张尺寸兼容。本应用依赖 PDA 自身扫码服务，不提供摄像头扫码。

## 主要功能

- 扫码自动登记、项目内 SN 去重、独立连续编号、手动补录。
- XLSX / CSV 资产清单导入、字段映射、SN 或资产ID核对、分类汇总、已盘 / 未盘筛选与重新盘点。
- 项目归档 / 恢复、记录搜索 / 编辑 / 侧滑删除、按范围导出与分享。
- 30 × 20 mm 标签模板、设备范围和份数设置、逐张预览、样稿、打印队列暂停与恢复。
- 成功声音与震动，独立异常提示音与试听，离线保存。

## 下载内容

- `pda-registry-v0.1.13-test.apk`：安装到 PDA 的公开测试包。
- `PDA扫码登记-操作手册.pdf`：完整图文操作手册，可离线查看和打印。
- `资产盘点导入模板.xlsx`：空白资产清单，填写第一张工作表。
- `pda-registry-v0.1.13-user-kit.zip`：包含 APK、PDF、模板和快速开始的用户资料包。
- `SHA256SUMS.txt`：附件 SHA-256 校验值。

首次使用：安装 APK → 项目页新建项目 → 设置启用直接接收 → 回到扫码页按侧键扫描。已有清单时通过“项目 → 导入项目”开始盘点。完整说明见仓库 `docs/USER_MANUAL.md` 或下载 PDF。
